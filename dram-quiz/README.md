# DRAM 가격, 얼마나 알고 있나요?

한국은행 DRAM 수출물가지수로 맞혀 보는 숫자 추측 퀴즈입니다. 5문항 · 1분.
숫자를 입력하면 바로 정답과 해설이 나오고, **근거 보기**에 기준 날짜·계산 방식·출처가 있습니다.

- Next.js 15 + TypeScript, 정적 페이지 1장
- API 서버와 데이터베이스 없음. 정답은 `src/data/quiz.json` 에만 있습니다

## 데이터

| 항목 | 값 |
| --- | --- |
| 출처 | 한국은행 ECOS · 4.3.1.3. 수출물가지수(품목별) (`402Y016`) |
| 품목 | DRAM (`30911201AA`) · 달러기준 · 2020=100 |
| 범위 | 연간 2005–2025, 월간 2014.01–2026.09 |
| 조회일 | 2026-10-31 |

생산자물가지수(`404Y016`)에도 DRAM이 있지만, 가중치가 크고(103.4‰) 1971년부터 이어지는 수출물가지수를 썼습니다.
DRAM은 달러로 거래되므로 달러기준(= 계약통화기준)을 골라 환율 효과를 뺐습니다.

| 파일 | 역할 |
| --- | --- |
| `data/ecos-dram.json` | ECOS에서 받은 원자료 그대로 |
| `scripts/build-quiz.mjs` | 원자료를 검증하고 정답을 계산해 `src/data/quiz.json` 생성 |
| `src/data/quiz.json` | 앱이 읽는 문항·정답·해설 |

검증 내용: 월별 값이 빠짐없이 이어지는지, 연간 값이 그 해 월평균과 같은지(0.5% 이내).
어긋나면 스크립트가 멈춥니다. 정답은 손으로 적지 않습니다.

| # | 문항 | 정답 | 계산 |

| 5 | 2016–2025년 중 전년보다 오른 해 | 5번 | 연간 지수 전년 대비 > 0 |

### 데이터 다시 받기

ECOS 원자료를 새로 받아 `data/ecos-dram.json` 의 `annual`, `monthly` 를 바꾼 뒤:

```bash
npm run data
```

ECOS Open API 예시 (인증키는 https://ecos.bok.or.kr/api/ 에서 무료 발급):

```
https://ecos.bok.or.kr/api/StatisticSearch/{인증키}/json/kr/1/200/402Y016/M/201401/202609/30911201AA/D
```

## 로컬 실행

Node.js 18.18 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:3000
```

배포용 빌드를 확인하려면:

```bash
npm run build
npm start          # http://localhost:3000
```

## Vercel 배포

### 방법 1. GitHub 연결 (권장)

1. 이 폴더를 GitHub 저장소에 올립니다
2. https://vercel.com/new 에서 저장소를 Import
3. 저장소 안에서 이 앱이 하위 폴더에 있다면 **Root Directory** 를 `dram-quiz` 로 지정
4. Framework Preset 이 **Next.js** 로 잡혔는지 확인하고 **Deploy**

이후에는 `git push` 할 때마다 자동으로 다시 배포됩니다. 환경 변수는 필요 없습니다.

### 방법 2. Vercel CLI

```bash
npm i -g vercel
cd dram-quiz
vercel          # 처음: 로그인, 프로젝트 연결 (미리보기 URL)
vercel --prod   # 운영 URL로 배포
```

무료(Hobby) 플랜으로 충분합니다. 서버 함수 없이 정적 페이지 하나만 나갑니다.
